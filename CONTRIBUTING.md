# Contributing

Thank you for helping improve Mac Video Remote.

## Issues and ideas

Bug reports, compatibility reports, and feature ideas are welcome through GitHub Issues. Please do not include pairing URLs, pairing codes, personal network information, or private account data.

Useful reports include:

- macOS version;
- application name and version;
- whether the application or video page had keyboard focus;
- expected and actual behavior;
- reproduction steps that do not expose private information.

## Code contributions

This is a source-available, copyright-retained project rather than an open-source project. Please open an Issue before preparing a pull request.

Code contributions cannot be merged unless the contributor and copyright holder first agree in writing on ownership and licensing. An unsolicited pull request does not grant the project permission to use the submitted code and does not transfer copyright.

## Security reports

Do not publish pairing or local-network vulnerabilities in a public Issue. Follow [SECURITY.md](SECURITY.md).
