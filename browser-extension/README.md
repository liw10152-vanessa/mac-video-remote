# 网页增强控制扩展

这个可选扩展让 Chrome、Edge 等 Chromium 浏览器直接控制当前网页中的 HTML5 `<video>`，提供精确倍速、固定跳转和按住临时 3× 加速。

## 安装

1. 先运行 Mac Video Remote，记下终端显示的六位配对码。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目中的整个 `browser-extension` 文件夹。
6. 打开扩展的“详细信息 → 扩展程序选项”。
7. 输入六位配对码并保存。
8. 刷新已经打开的视频网页。

如果夸克版本提供兼容的扩展管理页面，也可以按相同步骤加载；若没有，则会继续使用通用键盘模式。

## 工作方式

- 扩展只连接 `http://127.0.0.1:8765` 或 `http://localhost:8765`。
- 配对码保存在当前浏览器的本地扩展存储中。
- 只有当前可见、获得焦点并包含视频的页面才会轮询控制指令。
- 扩展不读取或上传浏览记录、账号信息、页面文字或视频内容。

这是未上架商店的本地开发者扩展。浏览器可能在重启后提示确认，属于开发者模式的正常行为。
